# Excel

In diesem Repo wird ausschließlich mit Excel gearbeitet. Die bereitgestellten Daten, die für dieses Projekt verwendet werden, sind schon vollständig bereinigt, um an dieser Stelle etwas Aufwand einsparen zu können. In meinem Fall wurden die Daten in SMS22 geladen und dann über Excel abgerufen. Da jedoch keine Probleme mit NULLs oder Ähnlichem in den Daten behoben werden müssen, ist es auch möglich, die Daten direkt in Excel einzulesen, um sich den Weg über SMS22 sparen zu können.

Die gegebenen Daten behandeln das Thema der Bankkredite. In Excel werden die aus den Daten hervorgehenden Merkmale in Grafiken aufbereitet, um aufzuzeigen, woraus sich die Fehlzeiten zusammensetzen. Dazu werden noch weitere Merkmale betrachtet. Der jetzige Umfang ist noch recht kurz gehalten. Es ließen sich mit den Daten noch weitere Grafiken erstellen. Zudem können die Daten dynamisch angepasst werden. Dies erfolgt mittels Buttons an der linken Seite des Reports.

Das Ganze ist erstmal recht simpel gehalten, um auch ohne Vorwissen etwas voranzukommen. Wenn die Zeit da ist, kommen vielleicht noch komplexere Varianten.
